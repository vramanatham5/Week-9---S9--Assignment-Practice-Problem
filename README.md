# Week 9 Assignment Practice Problems

This repository contains Java solutions for five object-oriented programming
practice problems. Each solution is in its own folder and has a `Main` class.

## Problems

1. [Movie Ticket Counter](./Problem1_MovieTicketCounter/)
2. [Parcel Shipping Desk](./Problem2_ParcelShippingDesk/)
3. [College Fee Counter](./Problem3_CollegeFeeCounter/)
4. [City Cab Fare Meter](./Problem4_CityCabFareMeter/)
5. [Home Appliance Energy Report](./Problem5_HomeApplianceEnergyReport/)

## Compile and run

Requires a Java JDK. From the repository root, compile and run a solution by
replacing `Problem1_MovieTicketCounter` with the desired problem folder:

```powershell
javac -d Problem1_MovieTicketCounter Problem1_MovieTicketCounter\Main.java
java -cp Problem1_MovieTicketCounter Main
```

Enter the input described in the problem statement. The compiled `.class` files
are included alongside each solution's source file.
